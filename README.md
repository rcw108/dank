# DANK Capital — investor app

Investors sign in with Supabase and see on their phone everything they see in their dank.capital account.

| Folder | What |
|---|---|
| `web/` | Next.js 16 PWA (later wrapped with Capacitor for App Store / Google Play) |
| `docs/client/` | Client-facing project documentation (open `index.html`) |
| `supabase/` | Migrations and Edge Functions (step 2) |
| `wordpress/dank-sync/` | WordPress → Supabase sync plugin (step 4) |
