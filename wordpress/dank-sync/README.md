# DANK Sync — плагин WordPress

Связывает dank.capital с приложением для инвесторов. Приложение показывает ровно то, что инвестор видит в кабинете на сайте.

- **Вход в приложение.** Приложение спрашивает сайт, есть ли пользователь с этим email и ролью `investor`. Код отправляется только инвесторам.
- **Цифры кабинета.** Плагин считает Current Capital, Present Capital по строкам, Interest Received, Net Annualized Return, итоги и Referral Bonus тем же кодом, что и страница кабинета: расчёт из шаблона темы `hello-theme-dank` перенесён без изменений и вызывает функции темы.
- **Только то, что видно в кабинете.** В приложение уходят цифры и строки таблицы, имя, обращение, телефон, компания и тема. Остальные поля (адрес, ссылки на контракты, банковские данные и т. п.) остаются на сайте.
- **Живые обновления.** При изменении полей или роли инвестора данные отправляются сразу; при изменении реферала — ещё и данные пригласившего. Раз в сутки, в 00:05 по Мехико, отправляются все инвесторы: проценты растут каждый день. Если приложение недоступно, отправка повторяется через 1, 2, 4 и 8 минут.
- **Контроль расчёта.** Если шаблон кабинета в теме изменится, на странице плагина появится предупреждение: расчёт нужно перенести заново (`tools/build.sh`).
- **Безопасность.** Все запросы подписаны общим секретом (HMAC-SHA256, окно 5 минут).

## Сборка
Код расчёта берётся из копии темы и в git не хранится.
```
sh wordpress/dank-sync/tools/build.sh [путь к hello-theme-dank]   # по умолчанию wordpress/theme-src/hello-theme-dank
```
Скрипт переносит расчёт, прогоняет тесты (включая сравнение с настоящей страницей кабинета) и собирает `wordpress/dist/dank-sync.zip`.

## Установка и обновление
1. WordPress → Плагины → Добавить новый → Загрузить плагин → `dank-sync.zip` (при обновлении — «Заменить текущую версию») → Активировать.
2. Настройки → **DANK Sync**: проверьте адрес приложения и роль, скопируйте **Secret**.
3. Vercel → проект dank → Settings → Environment Variables: `WP_SYNC_SECRET` = секрет → Redeploy.
4. DANK Sync → **Test connection** должно ответить «Connection works».

Секрет можно хранить в `wp-config.php`: `define('DANK_SYNC_SECRET', '...');` — он важнее значения из настроек.

## WP-CLI
```
wp dank-sync push --all              # отправить всех инвесторов
wp dank-sync push --user=113         # одного (ID или email)
wp dank-sync show --user=113         # показать, что получит приложение
```

## Тесты
```
cd web && npm run test:php        # подпись + сравнение с настоящей страницей кабинета
cd web && npm run test:contract   # плагин ↔ приложение
```
